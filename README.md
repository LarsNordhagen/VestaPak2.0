# VestaPak2.0
This is the code repository for the "Conscious Gear- VestaPak 2.0" Capstone team for CSE 423.

The goal of this project is to create a new version of Conscious Gear's VestaPak. The vestapak is a vest that holds drinking water for people and athletes to use during physical activity. The new version will implement sensors to track biometric statistics and the water content of the vest. The information will be sent to a mobile app where the user can view their information and receive feedback/suggestions back.
